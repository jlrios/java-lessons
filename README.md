# Programming Lessons with Java

This repository contains introductory programming material designed for students in technical high school programs.

The purpose of this repository is to organize and structure programming content using the Java programming language as the primary tool for learning the fundamentals of software development.

The material is intended to support students who are beginning their journey in programming, providing clear explanations, practical examples, and exercises aimed at developing logical thinking and problem-solving skills.

Throughout the lessons, students will explore the core elements of programming, starting with basic concepts and gradually progressing toward more structured program development.

---

## Topics Covered

The course introduces students to the fundamentals of programming using Java. The following topics are progressively covered:

- Introduction to programming
- Java basic syntax
- Variables and data types
- Input and output
- Conditional statements
- Loops
- Methods
- Basic problem solving
- Introduction to simple program design

---

## Repository Structure

The content in this repository is organized in the following way:

- **lessons/** → theoretical explanations and examples  
- **exercises/** → practice activities for students  
- **projects/** → small programming projects  
- **resources/** → additional material and references  

---

## How to Use This Material

This repository can be used both by teachers and students.

Teachers may use the lessons as a guide for classroom instruction, while students can review the examples and complete the exercises to reinforce their understanding of the topics.

The material is structured to support progressive learning, starting with fundamental programming concepts and gradually introducing more complex ideas.

---

## Language

All examples in this repository are implemented using **Java**.
